# Аврора

Отдельный лаунчер модов для **Workers & Resources: Soviet Republic** и мастер материалов моделей. Windows x64, WinUI 3, .NET 10, без установки .NET пользователем.

## Игроку

1. Скачайте `Aurora-Setup.exe` из последнего релиза этого репозитория и установите для своего пользователя.
2. Подпишитесь на мод в Steam Workshop. «Аврора» не скачивает графический мод из GitHub.
3. Откройте небольшую кнопку **Настройки** в нижней части меню, выберите папку `SovietRepublic` и нажмите **Найти моды**.
4. Выберите появившийся раздел, нажмите **Установить / обновить мод**, настройте переключатели и запустите игру.

Пустая библиотека означает отсутствие разделов модов. Поиск проверяет `mods/library/<mod>/acode.lnchr` и установленные библиотеки Steam `steamapps/workshop/content/784150/<item>/acode.lnchr`. Обычные Workshop-моды без этого файла продолжают обслуживаться самой игрой. Их наличие не означает совместимость с PBR.

Бета-функции изначально свёрнуты. Изменения переключателей применяются при следующем запуске игры. F9 открывает отдельную компактную панель графики в игре. **Консоль — альфа** находится в общих настройках и отвечает `In development` на любое сообщение; команды не выполняются.

На GitHub распространяется лаунчер с редактором. В пакет графического мода не входят цветовые текстурные паки, образцы машин или трава; единственная поставляемая текстура — общий однопиксельный `mods/glass_default.dds`.

## Мастер моделей

На главной странице нажмите **Мастер моделей**. Выберите NMF и MTL. Файлы `lod*.nmf` рядом с выбранным NMF подхватываются автоматически, другие можно добавить. Переключайте модель/LOD, выбирайте объекты в списке или щелчком по viewport, настраивайте материалы через **Настроить PBR**.

Для готового отдельного объекта окна нажмите **Сделать объект стеклом** и отметьте соответствующие объекты в остальных LOD. Используется общий `glass_default.dds`; новая текстура не нужна. Для окон внутри общего кузовного атласа выберите материал и **Стекло через альфа-маску**: DDS/PNG с UV модели, RGB — оттенок/разводы, A=0 вне окон, A>0 на стекле. Одновременно выбирается один способ разделения стекла. Маска сохраняется как RGBA8 `glass.dds` рядом с авторской моделью.

Экспорт создаёт новую папку и сохраняет исходники. Он сохраняет все выбранные LOD, переносит используемые MTL-текстуры, создаёт companion `.pbr`, переносит имеющийся `script.ini` с локальными путями LOD и проверяет его ссылки. Для собственного NMF без игрового `script.ini` результат — ресурсы модели, а не автоматически выдуманные характеристики новой машины. Упаковка Workshop и характеристики транспорта остаются средствами игры.

Поддержаны проверенные rigid NMF `B3DMH\0`/`fromObj`, потоки `0x40139`, `0x4013a`, `0x108`; отдельные файлы LOD. Skin, неизвестные потоки, встроенные многослойные LOD отклоняются. Альфа-разделение использует проверенный адаптер `0x40139/0x4013a`. Preview читает RGBA8, BC1, BC3, BC5 DDS; освещение в редакторе является приближённым предпросмотром, окончательный результат проверяется в игре. У смешанных треугольников границы маски локальная тень пока остаётся по целому треугольнику.

## Обновления и доверие

Лаунчер проверяет последний релиз `Av1ra/Aurora` при запуске и по кнопке. Установка обновления запускается пользователем. Пакет проверяется по SHA-256 и ECDSA P-256 подписи закреплённого издателя, распаковывается с проверкой путей и устанавливается отдельным процессом после закрытия текущего окна. Резервные копии приложения: `%LOCALAPPDATA%/Aurora/backups`; резервные копии модулей: `<игра>/mods/aurora-backups`.

`acode.lnchr` — подписанные данные, а не пароль и не исполняемый скрипт. При поиске DLL не загружаются в процесс лаунчера. Подпись подтверждает издателя и целостность, но не является антивирусной гарантией. Закрытый ключ не публикуется и не передаётся игрокам. Мод с более высокой `MinimumLauncher` отклоняется до обновления «Авроры»; при выпуске мода издатель задаёт требуемую версию лаунчера.

Собственная подпись модуля не заменяет Windows Authenticode. Текущая тестовая сборка EXE не имеет сертификата издателя Windows. SmartScreen/Defender могут показать предупреждение; приложение не отключает защиту, не создаёт исключений и не обходит блокировку. Для публичного распространения нужен выпуск с доверенным сертификатом/Artifact Signing и накопление репутации. Даже подпись не гарантирует отсутствия предупреждений: [документация Microsoft](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

## Разработчику

Схема модулей и публикация: [MODULES.md](MODULES.md). Проверки и ограничения: [VALIDATION.md](VALIDATION.md). `build.ps1` собирает лаунчер, редактор, backend и установщик. Нужны Windows SDK, Visual Studio C++ x64, .NET 10, Python с Pillow/NumPy и PyInstaller. Зависимости и результаты сборки не включаются в исходники.
