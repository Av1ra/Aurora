# Aurora 0.2

Aurora is a Windows launcher for mods in Workers & Resources: Soviet Republic. Discover compatible Workshop modules, configure graphics before playing, and launch the game from one place. The optional Model Editor helps prepare vehicle materials, PBR and glass with external LOD models.

**Aurora 0.2 preliminary build.** The full test package includes the editor, PBR and the independent FOV Changer module. See Releases for matching setup/ZIP files and known limits.

Start here: [Project map](PROJECT_MAP.md), [Development](docs/DEVELOPMENT.md), [Current status](docs/STATUS.md), [Player description](docs/RELEASE_DESCRIPTION.md).

Version remains 0.2 until the owner requests a change. Work is recorded by commit and CI run. Public releases require explicit approval from the owner.
