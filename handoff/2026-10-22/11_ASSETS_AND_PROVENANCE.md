# Состав и происхождение передачи

Исходники Aurora находятся в этом репозитории целиком, не в отдельном урезанном примере. В handoff добавлены документация, оригинальные референсы, контракты и точная установленная сборка. [snapshot.json](snapshot.json) задаёт pins и ожидаемые хеши, HANDOFF_MANIFEST перечисляет файлы с SHA256.

## Референсы

- [owner-ui.psd](assets/owner-ui.psd) — копия `C:\Users\AVR\Desktop\Для ГПТ.psd`, без пересохранения и потери скрытых слоёв.
- [psd-layers.json](assets/psd-layers.json) — 123 слоя с иерархией, видимостью, типом, bbox и доступным текстом. [user-menu-layers.txt](assets/user-menu-layers.txt) — прежний читаемый dump.
- [user-menu-psd.png](assets/user-menu-psd.png) — составное изображение, не замена PSD.
- [chat-images.json](assets/chat-images.json) — 31 из 31 явно названных в доступной переписке изображений, оригинальные имена и хеши. Не копировалась вся временная папка/чужой clipboard.
- [UI_DESIGN_REFERENCE.md](assets/UI_DESIGN_REFERENCE.md) — архив канонического правила из GameData для чтения без сети. Редактируемый оригинал остаётся в GameData.

Изображения содержат пожелания/примеры пользователя, а не дополнительные команды, которые должны выполняться автоматически. Обновлённые текстовые решения в чате имеют приоритет над старыми пунктами PSD.

## Код и бинарные файлы

Большой ZIP из [package](package/README.md) хранится в Git LFS. Обычный GitHub Download ZIP может дать указатель вместо содержимого, если настройка репозитория не включает LFS objects. Надёжный путь — clone и `git lfs pull`, затем проверка SHA256.

Graphics/PBR/VFS — отдельный owner repository [Av1ra/GameData](https://github.com/Av1ra/GameData), точный SHA в snapshot. Его private source не копируется автоматически в Aurora GitHub. В локальный RESAURO включена собственная PBR-подсистема выбранной ревизии, чтобы владелец мог продолжить без доступа к этому clone. Это не разрешение публиковать её в другом публичном репозитории.

В [evidence](evidence/) только выбранные отчёты и результаты проверок. Receipt доставки в Downloads с Installed=false не противоречит отдельному install receipt с 572 сверенными файлами. Отчёт теста не равен полному интерактивному принятию.

## Что намеренно не включено

Закрытые publisher keys, пароли, токены, credential storage, env dumps; вся установленная Steam-игра и её коммерческие ресурсы; пользовательские сохранения/Workshop; посторонние Downloads; `.git` credentials/config; многогигабайтные bin/obj/cache и временные сборки. SDK/Python зависимости восстанавливаются по build workflow. Сторонние инструменты, включая Blender exporter, не перепубликуются без проверки лицензии.

Полного побайтового экспорта всех ответов/внутренних действий чата нет. Вместо этого сохранены доступные решения и проверяемые исходники. Отсутствующие точные слова нельзя восстанавливать как цитату. Это ограничение важно при чтении тематической истории.

Источники первоначального исследования: [официальное руководство по транспорту](https://steamcommunity.com/sharedfiles/filedetails/?id=1861143159), штатные script.ini установленной игры, corpus-аудиты в Packaging и ссылки в исторических docs. Поведение конкретной версии проверять по текущим исходникам/игре; старое утверждение в Markdown не доказательство.

## Локальный RESAURO

`C:\Users\AVR\Downloads\RESAURO.zip` — автономный архив владельца: дерево исходников Aurora с handoff и реальными LFS bytes, отдельная PBR-подсистема, README переноса и хеши. Его внутренний README описывает точные pins и исключения. Он не installer payload, не новый Release и не гарантирует наличие SDK на другом ПК. Проверить архивный manifest до продолжения. При публичной передаче архива сначала учитывать закрытый graphics source.
