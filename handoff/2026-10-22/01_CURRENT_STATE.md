## Последние регрессии и исправления

1. Прозрачные меню: root-grid resource overrides не охватывали отдельные popup. Добавлены явные стили MenuFlyoutPresenter/FlyoutPresenter, непрозрачные кисти и прямое отключение menu SystemBackdrop при открытии. Есть светлая/тёмная/контрастная обработка.
2. Пропавшая верхняя панель: при перестройке меню была пропущена строка `grid.Children.Add(ScrollViewer{Content=toolbar})`. Восстановлена. Введён тест наличия панели.
3. Editor открывал Launcher: WinRT отклонил `new Setter(SystemBackdropProperty, null)`, конструктор Editor упал, catch открывал MainWindow. Недопустимый Setter удалён. Ошибки Editor теперь показывают окно ошибки Editor. Добавлен обязательный hidden WinUI construction check в build.
4. Зависание «Анимаций»: команда ждала выбор меша, но общий `busy` запрещал клики WebView. Для активного mesh picker viewport теперь доступен, другие команды остаются заблокированы. Есть «Выбрать/Отмена».
5. Колёса: mesh translation часто нулевая и не совпадает со ступицей. Тест теперь вычисляет геометрический центр отдельных компонентов, использует маски вершин, позволяет выбрать одно колесо. `tire1Shape` и другие номерные формы включены. T138 и Ikarus дали по шесть физических компонентов в проверенном чтении.
6. Поворотники: перепутана сторона X; native left расположен на положительном X. Исправлены группы/новые точки/слоты фар. Кнопки используют IsChecked; включение начинает фазу on, выключение очищает эффект, в том числе при старом RAF callback.
7. WATER_POINT вынесен из фар в «Эффекты». **Кнопка проверки струи удалена** по последнему запросу владельца.
