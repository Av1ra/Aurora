# Aurora 0.2: непрозрачные поверхности и проверка колёс

## Причины и изменения

- Предыдущее исправление задавало theme resources только корневой Grid. Выпадающие окна/вложенные меню имеют отдельное дерево popup, а MenuFlyoutPresenter по умолчанию включает SystemBackdrop с Desktop Acrylic. Теперь непрозрачный SolidColorBrush задаётся стилям MenuFlyoutPresenter/FlyoutPresenter непосредственно, SystemBackdrop у меню выключен, стили доступны вложенным popup через ресурсы приложения. Кнопки верхней панели также имеют явный непрозрачный фон. Светлая/тёмная/контрастная тема обновляют цвет кистей.
- Старый тест колёс считал translation матрицы меша центром ступицы. У штатного T138/Ikarus translation равна нулю, а колесо находится в смещённых вершинах. Поэтому оно уходило по дуге вокруг общего начала координат.
- Центр определяется по геометрии каждого физического компонента в локальном frame и переводится обратно в координаты viewport. Геометрически раздельные колёса одного меша имеют разные центры и маски вершин; перекрывающиеся компоненты шины/диска объединяются. Изменение идёт только по маске выбранного колеса, без разделения/переименования исходной модели.
- Добавлен выбор отдельного колеса и явный пункт «Все колёса». По умолчанию выбирается одно колесо. Поворот управляемых колёс доступен только соответствующим front meshes. Spin действует вокруг собственной оси, reset восстанавливает все колёса. Добавлены tire1Shape и остальные номерные tireNShape.

## Проверки

Core test: два колеса в одном меше, раздельные pivot/masks, преобразованный frame, номерные имена. JS test: одно колесо поворачивается вокруг ступицы, второе в том же меше остаётся неподвижным, reset точен, VAO сохраняется. Core/project/export, WinUI compilation и реальный WebGL проходят. Native read-only проверка на gravel_t138 и bus_ikr_260; отчёт ignored artifacts/editor-revision-06-native-wheels.log. Live UI/game acceptance не выполнялась. Метод геометрического центра рассчитан на обычные отдельные колёса; произвольно сваренную геометрию двух колёс он не превращает в две независимые детали.
