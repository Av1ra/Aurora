# Aurora 0.2: меню, выбор объектов и эффекты

Запрос владельца: устранить зависание анимаций и невозможность выбора модели, объединить механизм и timeline, убрать XYZ в модальном окне, объяснить FAMILY/PURCHASE_EXCLUDE/конную тягу, исправить поворотники, убрать проверку струи.

## Изменения

- Причина блокировки выбора: RunHistoryCommand держал busy до завершения PickMeshInViewport, а UpdateControls запрещал hit testing WebView при busy. Теперь viewport доступен во время meshPick, прочие команды остаются заблокированы. Progress и перекрывающие панели скрываются до подтверждения/отмены, затем восстанавливаются.
- Отдельный пункт «Анимации» убран. «Механизмы» содержит штатные механизмы и переход «Редактировать анимацию…». Для обычного нового клипа объект явно выбирается во viewport; у настроенной оси используется её меш. XYZ/угловые координаты скрыты в модальном редакторе, редактируются gizmo во viewport.
- При настройке точки прицепа/секции непосредственно доступен выбор родительского NMF/OBJ. Существующие JOINT offsets сохраняются. Если модель не задана, теперь есть действие, которое исправляет причину ошибки.
- «Конструкция транспорта» заменена «Оборудование» с именованными разделами: прицеп, водитель/крепления, конная тяга, авиация, сцепка поезда, волны, кабина. Недоступные классу разделы отключаются. Конная тяга не перечисляется вперемешку с дымом машины.
- «Варианты покупки» убраны из верхнего меню. В параметрах транспорта есть «Доступность и базовая модель»: FAMILY и PURCHASE_EXCLUDE. FAMILY не означает окраски; подписи говорят о наследовании и скрытии из списка покупки.
- В «Фары и фонари» отдельные левые/правые поворотники, несколько точек на каждой стороне; нативные LIGHT_BLINKER/LIGHT_BLINKER_TRAILER сохраняются. Координаты определяют сторону относительно основного pivot, с учётом поворота осей.
- Кнопки теста используют ToggleButton.IsChecked вместо неоднозначной прозрачности. Состояние сбрасывается при открытии другого документа. JS regression проверяет off/on/off и оставшийся RAF callback.
- WATER_POINT и дым прицепа перенесены в «Эффекты». Пожарная точка предлагается пожарной технике, дым секции — при наличии JOINT; существующие записи доступны для исправления. Прямо доступен обычный выхлоп. Проверка струи удалена с панели тестов по просьбе владельца; авторинг точки сохранён.

## Откуда параметры

Официальная документация script.ini: https://steamcommunity.com/sharedfiles/filedetails/?id=1861143159 . FAMILY наследует параметры базовой машины, например годы доступности. PURCHASE_EXCLUDE исключает объект из списка покупки. PARTICLE_MOVEMENT_JOINT задаёт выхлоп в координатах прицепа/задней секции.

Конная тяга подтверждена штатными файлами Early Start: media_soviet/dlc3/vehicles/h_single2/script.ini: HORSE, SINGLE_HORSE_POWER 1.8, HORSE_MATERIAL и HORSE_MESH. Это отдельные игровые директивы размещения/ресурсов/параметра лошади. Сборные названия разделов прежней UI были решением редактора, а не названиями разделов игры. Единицы SINGLE_HORSE_POWER не переименовываются в кВт/л.с. без отдельного подтверждения.

## Проверки

WinUI build, Core/project/export suite, JS viewport regression, isolated real WebGL. Новые Core проверки подтверждают раздельные категории эффекта/огня/конной тяги и prerequisite visibility. Нет интерактивной WinUI или игровой приёмки; работающую Aurora владельца агент не управляет. Ограничения engine binding из revision 04 остаются.


Дополнительная найденная ошибка: стороны поворотников были перепутаны. Сверены штатные tire_leftShape/tire_rightShape: bus_ikr_256 и bus_ikr_260 имеют centre X +1.059/-1.08, covered_t138 +1.051/-1.051. Поэтому левая сторона — положительный X локального frame. Исправлены фильтр точек, позиции новых левых/правых точек и порядок слотов фар. Тест учитывает повёрнутый/сдвинутый pivot. Мигание начинается с фазы «включено» при активации, а не со случайной фазы системного времени.
