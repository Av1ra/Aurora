# Aurora 0.2 — отчёт по транспортному редактору

22 октября 2026. Работа завершается по просьбе владельца. Версия сохранена: **0.2**, интерфейс — native WinUI. Публичный релиз не создавался.

## Что сделано

- **Создание без донора.** Встроены 88 профилей классов и 22 рабочих назначения для семи типов транспорта. Для начала проекта не требуется установленная модель из игры.
- **Составные машины.** Несколько объектов в одном переносимом .aur, независимые модели/LOD/материалы/скрипты; внутренние ссылки при экспорте превращаются в ссылки пакета. Проверен собственный поезд с головной и хвостовой секциями.
- **Связанные части.** Сохранение зависимостей прицепов, кабин, винтов и других частей вместе с их материалами и текстурами. Исправлены общие материалы корпуса/сочленения у штатных автобусов и троллейбусов.
- **Кабины и механизмы.** Покупная модель кабины отделена от рабочей сборки. Для самосвала и барабана есть диагностические оси/поворот в просмотре без изменения исходной геометрии и экспорта.
- **Импорт материалов.** Исправлены обработка конца MTL, совместимые повторные определения, UTF-8 имена NMF, точное различение локальных и игровых путей текстур. Частичные определения можно открыть и дополнить; неизвестным слотам не назначаются случайные текстуры.
- **Экспорт.** Согласованы пути в .aur, материалах связанных частей и нескольких окрасках. Создание стекла не захватывает отключённые блоки MTL. Неиспользованные слоты NMF не требуют фиктивных материалов.
- **Надёжность.** Предел OBJ применяется до чтения файла; результат асинхронного импорта не попадает в другой выбранный параметр. Уточнены подтверждённые параметры рабочих ролей, без выдуманных единиц у неизвестных аргументов.

## Что проверено

- Полный Aurora.Tests: **547 проверок PASS**, в том числе неизменный roundtrip **1 073 script.ini** и **5 672 типизированных записей**.
- Сквозной тест всех семи типов: собственный OBJ → переносимый .aur → повторное открытие → экспорт с LOD, bbox, native/PBR материалами и текстурами.
- Повторный аудит материалов: **3 854 варианта**. Число объектов с прекращением импорта материалов сократилось **со 158 до 18**.
- WinUI-модуль: **0 предупреждений, 0 ошибок**.
- В отдельном headless WebGL проверены покупная/рабочая сборки кабины и диагностическая поза миксера. Это не проверка игры и не приёмка всех диалогов.

## Что осталось

1. У **18 объектов** отсутствуют файлы по исходным ссылкам текстур. Они перечислены в [сводке аудита](audit-data/transport-material-import-2026-10-22.json); автоматической подмены нет.
2. У **124 объектов / 631 варианта** определения материалов частичные. Открытие для исправления работает; готовность этих объектов к экспорту не заявляется.
3. **9 основных NMF** используют неподдержанный поток. Работа с анимациями отложена по решению владельца.
4. Новые диалоги и точное игровое поведение частей требуют отдельной проверки. Файловые тесты не доказывают приём модов игрой.
5. Выбор единиц есть у главного OBJ; единообразное окно единиц для импорта частей и LOD остаётся доработкой.

Полная настройка транспорта заметно расширена, но весь согласованный объём завершённым не объявляется. Отложенные идеи для лаунчера, песочницы и UI-плагина не реализовывались.
