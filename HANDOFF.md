# Аврора 0.1.1 — состояние проекта

Новый публичный источник приложения: https://github.com/Av1ra/Aurora . Финальная раздача — только лаунчер с редактором; графический runtime подготовлен для отдельного Workshop-модуля.

Реализованы динамический каталог из подписанных acode.lnchr, SHA-256 файлов и закреплённый ключ ECDSA P-256, сканирование нескольких Steam libraries, пустое меню при отсутствии модулей, отдельные настройки, обновления из публичного GitHub, alpha-консоль In development, WinUI-редактор NMF/MTL с viewport, PBR и двумя способами стекла. Отдельные LOD сохраняются, исходники не изменяются. В graphics payload только pbr.dll, m.dll и glass_default.dds (132 bytes), без текстурных паков/травы/примеров машин.

Последняя правка интерфейса: своя верхняя панель в теме окна вместо белой системной полосы; сохраняются штатные кнопки окна. Пункт языка — NavigationViewItem с иконкой и всплывающими RU/EN; при сжатии боковой панели остаётся иконка. Изображение игры имеет фиксированный размер и Stretch.Uniform, не увеличивается при сжатии меню.

Проверки: 178/180 rigid NMF приняты; неподдержанные 2 отклонены. Экспорт AMO main/lod1/lod2 в режимах PBR, object glass и alpha glass; исходные файлы не меняются. Все 3 экспортированных companion-файла разобраны настоящим PbrParser. Исправлена найденная проверками ошибка normal_y: теперь directx/opengl, числовое значение не экспортируется. Installer fixture проверяет rollback при коллизии и сохранение INI. Установка предыдущей общей сборки 0.1.0 проверила все 1130 файлов по SHA; текущая 0.1.1 меняет оформление, итоговый manifest ZIP проверяется при публикации.

Bootstrap fixture: PASS ранние m.dll/pbr.dll, WARP и CWD. Без C3D runtime gate ожидаемо задерживает fixture дольше 10 секунд; первоначальный короткий timeout был ложным диагнозом зависания. В настоящий процесс игры в этой задаче не запускали.

VFS больше не ставит модовые папки отдельным первым блоком: объединённая выдача сортируется по имени папки. Сортировка магазина по отображаемому локализованному имени ещё не подтверждена. Интерактивный F9 conflict logger test локально по-прежнему FAIL; остальные обязательные стадии были отдельно выполнены exit0. Не объявлять весь build-win зелёным.

Windows Authenticode сертификата пока нет. Криптографическая подпись acode/обновлений не равна Windows-подписи EXE и не гарантирует отсутствие предупреждений SmartScreen/Defender. Защита не отключается, исключения не добавляются. Приватный publisher key хранится вне исходников и релизов, путь/содержимое не публиковать.

Обычный upload Workshop средствами игры не выполнялся: подготовлена подписанная папка. Дополнительная игровая проверка автора нужна перед массовой публикацией. Не подменять это фиктивными скриншотами/обещанием полной поддержки всех NMF.

Локально: D:/PBR-Development/Aurora ; релизы D:/PBR-Release/Aurora ; архив старых релизов D:/PBR-Release/Aurora/legacy-releases. Текущее рабочее окружение игры D:/SteamLibrary/steamapps/common/SovietRepublic. Установленные пользовательские INI сохранены. Старый пользовательский pbr.exe остаётся для отката; новый основной вход — Аврора.
## Обновление упаковки 0.1.2

Основной лаунчер отделён от необязательного мастера моделей. Native Win32 setup вместо WinForms self-contained; выбор папки лаунчера и игры, сохранение install-root/game-path. WinUI granular package без AI/ML. Editor.Module загружается только после проверки официальной подписи и хешей; backend/viewport отдельным asset + aurora-editor.json. Общий runtime повторно не поставляется.

UI: функции в карточках, отдельные Beta/Alpha badge; бета в свёрнутом Expander; настройки сгруппированы по игре/модам, консоли, приложению. В названии приложения нет версии. Разделитель middle dot удалён из UI.

Новый build.ps1 собирает main и addon раздельно, build-setup.ps1 упаковывает основной ZIP в компактный native EXE. Packaging/test-native.py принимает путь к native Aurora.Installer.exe. Packaging/legacy-files.tsv позволяет архивировать только совпадающие старые файлы, оставляя пользовательские изменения и новый подписанный Editor.
